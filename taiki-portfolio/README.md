# Taiki Lowe portfolio

A standalone, responsive portfolio site with no build step or template dependency.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static hosting provider. The site is ready for GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

## Updating content

- Homepage content and project links live in `index.html`.
- Project case studies are in `projects/`.
- Shared visual styling is in `styles.css`.
